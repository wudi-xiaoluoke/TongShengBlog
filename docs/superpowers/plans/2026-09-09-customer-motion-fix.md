# 顾客动作连贯性修正

用户已确认人物画法，要求修复播放不连贯。原始生成图存在重复步态、逐帧身体漂移和错误的背景，不适合作为连续动画直接播放。

修正保持头部与外套贴图固定，使用最初已有的透明同款人物画稿作为运行时纹理源。Canvas 绘制器分离躯干与袖子，使用双段腿部关节完成左右脚交替，左右侧面使用一致的镜像轮廓。每方向 16 帧，每帧 50ms，一周期 800ms。没有修改生产游戏状态、寻路、经济逻辑或用户存档。

## 侧面倒走修正
用户指出左右侧面倒走。新增测试首先失败，定位为抬脚阶段的前后位移符号反了。修正后，腾空脚向面朝方向前送，落地脚相对身体向后移动；摆臂同步相反。3 项步态测试和浏览器回归通过，64 张帧、条带与 ZIP 已重新导出。缓存版本更新为 20260909-forward。

## 侧面摆臂修正
原先只有一条偏后的侧面手臂且始终位于躯干下层。改为从中性袖子贴图围绕肩部摆动，两条手臂反相运动，绘制顺序为远侧手臂、躯干、近侧手臂。check-customer-arms.cjs 通过实际渲染像素比较半周期差异，排除静止内搭颜色，验证左右侧面手掌都能出现在身体前后；该测试修复前失败、修复后通过。3 项步态测试仍通过，64 张序列帧和 ZIP 已更新。缓存版本 20260909-arms。
