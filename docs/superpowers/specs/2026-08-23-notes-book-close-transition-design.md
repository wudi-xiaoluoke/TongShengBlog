# 手账书合拢—停顿—展开动画修订设计

日期：2026-08-23  
状态：已与用户确认，待书面审阅

## 背景

`/notes` 已实现指定页或月份跳转时的合书动画，但当前左右书页和封壳同时旋转到接近 90°，闭合后只剩中央窄色块。这个过程更像两扇门缩进中线，书页、封壳和纸张厚度没有形成统一的书本实体。

本次修订只改善指定位置跳转时的“合拢—停顿—展开”效果，不改变普通翻页、文章数据、导航入口或后端逻辑。

## 已确认的动作语义

1. 当前左右书页从两侧同步向中缝合拢。
2. 完全闭合后，画面中央显示一条有明确厚度的书脊侧面，而不是完整封面。
3. 闭合态利落停顿约 220ms，并在遮挡期间切换目标双页。
4. 目标书页从中缝同步向左右展开。

## 采用方案

采用“3D 合页 + 中央厚书脊接管”。左右书页继续使用真实 `rotateY` 表现绕中缝转动；中央厚书脊不参与整段旋转，只在页面接近闭合时淡入并接管闭合轮廓。

未采用纯 `scaleX` 收缩，因为它缺少绕轴旋转的空间感；未采用覆盖整本书的独立动画副本，因为其 DOM 复制、响应式适配和后续维护成本超出本次范围。

## 动画阶段

### 合拢

- 时长约 380ms。
- 左页围绕右边缘从 `0deg` 转到约 `86deg`；右页围绕左边缘从 `0deg` 转到约 `-86deg`。
- 左右页同步运动，不能先后合拢。
- 封壳跟随对应书页运动，并始终比纸页略大，保留封壳包边。
- 页面阴影随角度向中缝收紧，避免旋转末段出现大面积漂浮阴影。
- 最后约 80ms 内，中央厚书脊侧面由透明渐显。

### 闭合停顿

- 中央厚书脊宽度在桌面端约 28–36px；移动端可按书本宽度缩小，但不能退化成无厚度细线。
- 书脊侧面包含上下封壳包边、重复纸页细线、中间窄高光和克制的落影。
- 闭合态停顿约 220ms，强调一次短促、明确的节拍。
- 目标 spread、页码和月份索引只在中央书脊完全可见后更新，换页过程不可见。

### 展开

- 时长约 430ms。
- 目标左右书页从约 `±86deg` 同步回到 `0deg`。
- 中央厚书脊在展开初段淡出，不能压在已打开的页面上。
- 展开结束后恢复文章链接、按钮和拖动交互。

## 状态与职责

保留现有 `idle → closing → closed → opening → idle` 状态流和 `jumpTo()` 入口。

- JavaScript 负责阶段切换、目标页更新、操作锁定以及 `transitionend`/超时兜底。
- CSS 负责左右页和封壳的 3D 姿态、厚书脊显隐、阴影与动画曲线。
- `.book-page-block` 调整为闭合态视觉实体，并在合拢末段、停顿期和展开初段拥有明确的显隐规则。
- 任何完成路径都必须移除跳转类名并恢复 `idle`，不能永久锁定交互。

## 响应式与降级

- 桌面端和移动端都保留左右双页同步合拢。
- 移动端降低书脊侧面宽度、纸页线密度和阴影强度，保持中央厚度可辨识。
- `prefers-reduced-motion: reduce` 或不支持 3D transform 时继续使用现有淡入淡出切换，不显示伪 3D 厚书脊。
- 动画期间禁止重复跳转、普通翻页和拖动输入。

## 测试与验收

### 自动化验证

- 合书状态仍严格按 `closing → closed → opening → idle` 迁移。
- 仅在 `closed` 后激活目标 spread。
- `transitionend` 正常路径和超时兜底都能完成并清理状态。
- 动画期间重复输入不会创建第二个跳转流程。
- reduced-motion 分支仍直接完成目标内容切换。

### 视觉验收

- 左右页从两侧同时向中间合拢，没有明显先后或横向漂移。
- 闭合态中央是一条 28–36px 左右、有纸页分层和封壳包边的书脊侧面，而不是单色细线。
- 停顿利落，约 220ms；目标内容切换不可见。
- 打开时左右页从中间同步展开，中央书脊及时淡出。
- 动画结束后页面位置不跳动，文章与导航交互恢复。

## 涉及文件

- `src/main/resources/static/css/notes.css`：修订合拢、闭合书脊、展开、阴影和响应式样式。
- `src/main/resources/static/js/notes.mjs`：调整阶段时长和中央书脊显隐的时序协作，保留现有状态机。
- `tests/notes-book.test.mjs`：补充或调整跳转阶段与清理行为测试。

模板与后端数据结构不修改；`.book-page-block` 的上下封壳包边使用 CSS 伪元素表达。
