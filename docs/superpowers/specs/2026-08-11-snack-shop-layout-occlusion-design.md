# 零食店货架布局与角色遮挡修复设计

## 目标

修正当前货架过于靠近店门和街道、收银台遮住店长，以及货架前沿无条件覆盖角色的问题。保留两排共六个货架、现有库存与顾客经营流程。

## 店内布局

- 第一排三个货架沿店铺后墙布置，表现为墙面货架。
- 第二排三个货架位于店铺中央，表现为中岛货架。
- 两排货架之间保留横向选购通道；中岛货架与门口之间保留进出通道。
- 收银台位于店铺右侧靠墙区域，与最近货架之间保留通向收银区的纵向通道。
- 店长固定站在收银台内侧，头部和上半身完整可见。

## 角色动线

顾客从右下方门口进入，通过门口主通道前往中央通道，再按目标货架进入对应选购点。选购结束后沿右侧通道进入收银队列，结账后从原入口离店。所有路线点必须位于家具碰撞区域之外。

## 遮挡规则

- 家具与角色统一使用脚点（Y 坐标）排序。
- 角色脚点在货架底边之后时，角色完整绘制在货架前方；在货架底边之前时，由货架遮挡角色下部。
- 不再在场景末尾统一重画全部货架前沿。
- 收银台按 46% 高度拆成互不重叠的后层与前挡板：先绘制上部后层，再绘制店长，最后绘制下部前挡板，使店长腿部自然被柜台遮挡但身体可见。两块素材边界精确相接，避免半透明像素重复合成后边缘变深。
- 货架选中框、缺货标记与顾客需求气泡仍保持在最终交互层。

## 验收标准

- 六个货架均位于店内，其中三个贴后墙、三个处于店中央。
- 中岛货架不贴近门口或街道区域。
- 店长的头部和上半身持续可见，收银台仅自然遮挡腿部。
- 顾客经过货架前后时遮挡关系正确，不出现无关货架横条压住角色。
- 世界布局校验、场景绘制测试、顾客路线测试和现有完整测试全部通过。
