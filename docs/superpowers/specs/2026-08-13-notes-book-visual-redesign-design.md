# 手帐页书本造型与翻页交互改版设计

日期：2026-08-13  
状态：已与用户确认，待书面审阅

## 背景

现有 `/notes` 已具备按月份分组、左右双页展示、上一组/下一组翻页和月份索引跳转。当前问题集中在表现层：木纹桌面、厚重皮革和两块平面纸页更像“卡片嵌在木框里”，书本造型不够精致；现有翻页缺少明确的纸张刚度和完整页面感。

本次改版不改变文章数据、月份分组和后端路由，只重做书本视觉、逐页翻动、指定页/月份跳转和相关控制。

## 目标

- 书本呈现为简洁、精致的现代插画书，同时与网站既有手帐风格保持统一。
- 普通前后翻页表现为有挺度的整张纸，以书脊为轴完整翻过。
- 指定页码或月份跳转使用“整书合拢、厚书页停顿、打开到目标位置”的独立动画。
- 桌面端和手机端均保留左右双页结构。
- 静止状态继续使用可选择、可点击、对搜索引擎和辅助技术友好的 HTML 内容。

## 非目标

- 不改变 `/notes` 的后端查询、月份分组和文章排序规则。
- 不增加搜索、分类筛选、服务端分页或新的文章字段。
- 不使用软纸卷角、波浪形弯曲、布料式回弹或 Canvas 软体网格卷页。
- 不重做全站页头、页脚、首页或文章详情页。

## 视觉方向

### 与全站统一

继续使用 `home.css` 已建立的视觉语言：

- 页面背景：暖米色 `#faf3e3`。
- 书页：奶油白 `#fffdf4`，辅以 `#eadcc0`、`#d9c8a8` 的边线和纸张层次。
- 主文字：`#5a4632`；次要文字：`#8a7355`、`#b39a77`。
- 强调色：橙棕 `#d1662f`。
- 字体：延续 `KaiTi`、`STKaiti`、`Kaiti SC`、`PingFang SC` 的既有字体栈。
- 装饰：保留粉色纸胶带、便签、虚线、低饱和植物或日光线稿；装饰不能覆盖文章内容。

“现代”来自轻薄、克制、边缘清晰的书本轮廓和更少的材质噪声，而不是引入冷色无衬线视觉体系。

### 书本结构

- 移除木纹桌面背景和深色粗重书脊。
- 使用轻薄橙棕布面封壳，封壳只在书页外缘露出少量边框。
- 左右纸页使用细微明暗渐变表现中缝、外缘和纸张厚度。
- 中间书脊以窄幅阴影和高光表现，不使用粗黑分隔条。
- 纸页边缘通过 2–3 层错位边线表现厚度，不堆叠大量拟真纹理。
- 每页保留月份标题、日期、文章标题、摘要、分类和阅读量；移动端可隐藏部分摘要和装饰，但不能隐藏标题与月份。

## 普通翻页：整张硬纸翻动

### 动作语义

“上一页/下一页”以及方向键操作均触发整页硬翻。下一组时，当前右页围绕中间书脊向左翻；上一组时，当前左页向右翻。

翻动页在整个过程中保持完整矩形和平整轮廓：

1. 整张页面从书脊同时抬起。
2. 页面围绕书脊旋转，形变量极小。
3. 越过 90° 时显示页面背面和目标页对应内容。
4. 整页落到另一侧，以一次短促阴影收束结束，不做柔软回弹。

单次自动翻页目标时长为 650–750ms。动画曲线前段略慢、中段较快、落页短暂停顿，形成厚挺插画纸的重量感。

### 输入方式

- 点击“上一组/下一组”按钮：自动完成一次硬纸翻页。
- 键盘 `ArrowLeft` / `ArrowRight`：与按钮一致。
- 鼠标或触摸横向拖动：整页旋转角度跟随横向位移，不产生卷角或波浪。
- 拖动超过页面宽度的 45% 后完成翻页，否则退回原位。
- 动画或自动收束期间锁定下一次输入，防止页面交叉或状态错位。
- 文章区域仍可点击；拖动仅在达到最小横向位移后接管指针，短点击不会被误判为翻页。

## 指定页或时间跳转：合拢后重开

### 跳转入口

- 中间页码由静态文本改为可点击控件，例如“第 1 / 6 页”。点击后展开双页组列表，每项显示页码和对应月份区间。
- 书下方月份索引改为每个月单独可点击。点击月份后跳到包含该月份的双页组。
- 两种入口都调用同一个 `jumpTo(spreadIndex)` 流程。

### 动画序列

1. 左右书页与封壳同时向中间合拢，约 420ms。
2. 闭合状态露出中间厚书页切口。切口使用多层细线或重复渐变表现纸张厚度，而不是单一色块。
3. 完全闭合后停顿约 280ms，显示“翻到 · YYYY.MM”或目标页码，避免用户误认为卡顿。
4. 在闭合遮挡期间切换激活的双页组、页码和月份索引状态。
5. 书从中间向左右打开到目标双页，约 480ms。

总时长约 1.2 秒。若目标就是当前双页，不播放动画。

## 前端结构

### 保留的结构

- Thymeleaf 继续一次性渲染全部 `book-spread`。
- 每个 spread 继续包含左、右两页；奇数月份的最后一组继续使用空白右页。
- 后端 `MonthGroup`、`Spread` 和 `/notes` 控制器逻辑不变。

### 新的表现层单元

- `BookView`：缓存 spread、控制激活项并同步页码和月份索引。
- `RigidPageTurner`：创建临时双面翻动页，管理拖动进度、自动完成和退回。
- `BookJumpTransition`：管理合拢、闭合停顿、内容切换和重新打开。
- `BookState`：统一保存 `currentIndex`、`phase`、`direction`、`progress` 和 `targetIndex`。

状态 `phase` 只允许以下值：

- `idle`：可点击文章并接受新操作。
- `dragging`：整页角度跟随指针。
- `settling`：完成翻页或退回原位。
- `closing`：指定页/时间跳转正在合拢。
- `closed`：书已闭合并等待目标内容切换。
- `opening`：目标双页正在重新打开。

只有 `idle` 可以发起新的翻页或跳转，确保两套动画不会并发。

### 翻动页实现

- 静止页面始终是真实 DOM。
- 动画开始时，从源页和目标页复制必要的页面内容到临时 `.turning-sheet` 的正反面。
- `.turning-sheet` 使用 `transform-origin` 固定在书脊，配合 `perspective`、`rotateY`、`backface-visibility` 和动态阴影表现完整硬纸页。
- 动画结束后更新真实 spread，移除临时层并恢复文章交互。
- 不引入 Canvas 或第三方翻页库；最终确认的“硬纸整页”不需要软体网格模拟。

## 响应式设计

- 桌面端保持完整左右双页、摘要和装饰插画。
- 手机端仍保持左右双页，不切换为单页。
- 手机端减小内边距、字号、标签间距和装饰尺寸；摘要最多保留一行，空间不足时隐藏摘要。
- 月份、文章标题、日期和翻页操作必须保持可见。
- 书本宽度跟随视口缩放，但触摸目标最小高度保持 40px。
- 月份索引允许横向滚动或折行，不能挤压书本主体。

## 可访问性与降级

- “上一组”“下一组”、页码选择器和月份索引使用原生按钮或等效可聚焦元素，并提供明确的 `aria-label`。
- 翻页结束后更新 `aria-hidden`，只让当前双页进入辅助技术的阅读顺序。
- `prefers-reduced-motion: reduce` 下不执行 3D 翻转，改为 150–200ms 的淡入淡出；指定跳转仍更新目标内容和控件状态。
- JavaScript 不可用时，所有 spread 按时间顺序纵向排列，文章链接保持可用。
- 浏览器不支持所需 3D CSS 时，自动使用淡入淡出切换，不阻断导航。
- 动画超时必须调用统一的完成清理函数，避免 `transitionend` 未触发时永久锁定操作。

## 测试

### 纯逻辑测试

- `next`、`prev`、`clamp` 和首尾边界保持正确。
- 拖动进度转换为角度的计算正确。
- 45% 阈值两侧分别完成和取消翻页。
- 非 `idle` 状态拒绝新的翻页或跳转。
- 页码和月份都能映射到正确的 spread。
- 跳转当前 spread 不触发状态变化。

### DOM 与交互测试

- 前翻使用当前右页正面和目标左页背面；后翻方向相反。
- 翻页完成后只激活目标 spread，临时翻动页被移除。
- 拖动取消后索引不变，页面恢复原位。
- 连续点击不会生成多个翻动层。
- 页码选择器和单月索引均触发合拢跳转。
- 合拢期间在完全闭合后才替换内容。
- 动画结束、超时兜底和 reduced-motion 分支均能恢复 `idle`。

### 视觉与设备验证

- 桌面端检查书脊轴心、正反面、动态阴影和落页层级。
- 手机端检查左右双页、标题可读性、触摸拖动和月份索引。
- 检查首组、末组和右页为空的最后一组。
- 检查长标题、长摘要、单月文章较多和无文章状态。
- 对比全站页头、便签、纸胶带、字体与颜色，确认视觉语言一致。

## 验收标准

- 书本与首页使用同一暖色、手写字体和手帐装饰体系，不再出现木桌框和粗重深色书脊。
- 前后翻页时整张纸始终保持完整、厚挺的平面感。
- 页码和任意单月均可直接跳转，并播放“合拢—厚书页停顿—打开”动画。
- 桌面端与手机端均保留左右双页。
- 动画不会导致文章链接误触、页面交叉、操作永久锁定或内容丢失。
- reduced-motion、无 JavaScript 和不支持 3D CSS 的场景仍可浏览全部文章。
