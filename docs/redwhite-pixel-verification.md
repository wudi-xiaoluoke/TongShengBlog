# 红白像素店重构与验收

日期：2026-09-07。用户批准现代红白零食店方向，并要求四季与日夜结构完全统一。

## 实现

- 原世界几何、柜位命中区、收银台和进出店动线保持一致。四季与日夜使用同一个 renderer；不会切换不同背景图片。
- 重绘白色金属货架、红色价签、灰白地砖、玻璃门窗、商品包装、四方向人物及室外树木。
- 每柜真实显示四行×三格，按实际在架数量优先向顾客取货的主货柜分配显示，商品不会在多个柜位重复计算。
- 游戏时钟控制连续光照。夜间室内仍可读；天气与积雪仅在室外。季节规则仍跟随真实月份。
- HUD 位于画布上方；手机五页、库存筛选、补货与换排面、夜间双页订货及重新开店确认保留。新增手机关闭按钮。
- game-config.mjs、game-state.mjs、game-customer.mjs、game-world.mjs 与所有后端文件未修改。main.mjs 只修改表现层 import 的资源版本。
